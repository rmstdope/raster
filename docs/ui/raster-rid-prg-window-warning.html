raster-rid — warning that a bank data write repointed a PRG window

Agreed with the navigator over three rounds. The caret sits on the mmc3.bank_data write, because the select on its own changes nothing and the data write is the instruction that moves the window. A definite message when rasterc can see which register is selected, a softer one when it cannot, and silence for R0–R5, which are the CHR windows and the ordinary use of these registers.

1 · R6 selected — the $8000 window moves

main { mmc3.bank_select = 6 mmc3.bank_data = 2 }
warning: this write repoints the PRG window at $8000 --> demo.raster:3:5 | 3 | mmc3.bank_data = 2 | ^^^^^^^^^^^^^^^^^^ R6 is selected, so this replaces $8000-$9FFF = note: reset chose a linear 32 KiB map with R6 = 0 and R7 = 1; the bytes at $8000 are not the ones it mapped from here on = note: PRG bank switching is not supported yet: banks 0 to 2 hold $FF, and bank 3 is a second view of the fixed bank at $E000

3 · No select at all — reset left R7 selected

Reset's last bank select is $07, so a bank data write with nothing before it lands on R7. This is the case an author is least likely to expect, and the one rasterc can name most precisely.

main { mmc3.bank_data = 0 }
warning: this write repoints the PRG window at $A000 --> bare.raster:2:5 | 2 | mmc3.bank_data = 0 | ^^^^^^^^^^^^^^^^^^ nothing selects a register before this, and reset selected R7 last = note: reset chose a linear 32 KiB map with R6 = 0 and R7 = 1; the bytes at $A000 are not the ones it mapped from here on = note: write mmc3.bank_select with 0 to 5 first to point this at a CHR window

4 · rasterc cannot see which register is selected

main { var which: u8 = 3 mmc3.bank_select = which mmc3.bank_data = 2 }
warning: rasterc cannot tell whether this bank select changes the mapping mode --> unknown.raster:3:5 | 3 | mmc3.bank_select = which | ^^^^^^^^^^^^^^^^^^^^^^^^ rasterc cannot see this value here, so bits 6 and 7 are unknown = note: bit 6 is PRG mode and bit 7 is CHR A12 inversion; keeping both clear keeps the map reset chose warning: rasterc cannot tell which bank register this write lands on --> unknown.raster:4:5 | 4 | mmc3.bank_data = 2 | ^^^^^^^^^^^^^^^^^^ the last bank select before this is not one rasterc can see = note: R6 and R7 are the two 8 KiB PRG windows; a write landing on either one repoints $8000 or $A000 = note: selecting with a literal 0 to 5 immediately before the write keeps the map reset chose

The first warning is the one raster-6jr already ships; the second is this bead's. Two warnings for one mistake was weighed and kept: they say different things, and the author who wrote a computed select needs both.

5 · The ordinary CHR case — silent

main { mmc3.bank_select = 0 mmc3.bank_data = 3 mmc3.bank_select = 2 mmc3.bank_data = 9 }
Compiling demo.raster Finished demo.nes in 0.04s

R0–R5 are the CHR windows. Nothing is said, on every build, for ever — this is the case the warning must never touch.

6 · A CHR animation loop — silent

The select is outside the loop and the data write inside it. Nothing in the body writes bank_select or calls anything that can, so the selection is still R0 on every iteration.

main { mmc3.bank_select = 0 while frame != 0 { mmc3.bank_data = tile } }
Compiling anim.raster Finished anim.nes in 0.04s

7 · A loop whose body selects — the second iteration is what matters

On the first iteration R0 is selected; on every one after it, R6. rasterc looks at the body before lowering it, sees a bank_select write, and judges the whole body with the selection unknown — which is the only answer true of every iteration.

main { mmc3.bank_select = 0 while count != 0 { mmc3.bank_data = count mmc3.bank_select = 6 } }
warning: rasterc cannot tell which bank register this write lands on --> loop.raster:4:9 | 4 | mmc3.bank_data = count | ^^^^^^^^^^^^^^^^^^^^^^ the last bank select before this is not one rasterc can see = note: R6 and R7 are the two 8 KiB PRG windows; a write landing on either one repoints $8000 or $A000 = note: selecting with a literal 0 to 5 immediately before the write keeps the map reset chose

One warning, not one per iteration: a warning belongs to a source line, and the line appears once.

8 · A helper function

A fn can be called with any register selected, so its body starts from an unknown selection. The fix is one line inside the helper.

fn set_chr(tile: u8) { mmc3.bank_data = tile } main { mmc3.bank_select = 0 set_chr(3) }
warning: rasterc cannot tell which bank register this write lands on --> helper.raster:2:5 | 2 | mmc3.bank_data = tile | ^^^^^^^^^^^^^^^^^^^^^ this function can be called with any register selected = note: R6 and R7 are the two 8 KiB PRG windows; a write landing on either one repoints $8000 or $A000 = note: selecting with a literal 0 to 5 in this function, before the write, keeps the map reset chose

10 · A call between the select and the data write

Only a call that can reach a bank_select write clears what rasterc knows. bump() increments a counter and is transparent; tick() selects, so the write after it falls to the softer message.

fn bump() { counter = counter + 1 } fn tick() { mmc3.bank_select = 6 } main { mmc3.bank_select = 0 bump() mmc3.bank_data = 3 // silent: bump() cannot select tick() mmc3.bank_data = 4 // warns: tick() can }
warning: rasterc cannot tell which bank register this write lands on --> calls.raster:9:5 | 9 | mmc3.bank_data = 4 | ^^^^^^^^^^^^^^^^^^ the last bank select before this is not one rasterc can see = note: R6 and R7 are the two 8 KiB PRG windows; a write landing on either one repoints $8000 or $A000 = note: selecting with a literal 0 to 5 immediately before the write keeps the map reset chose

Carrying which register tick() leaves selected, so this could say “R6 is selected”, was considered and declined: it needs a second evaluator over the syntax tree kept in step with the one over the lowering. Filed as a follow-up instead.

11 · A select that changes the mode and names R6

Bits 0 to 2 of a select name the register, so $46 selects R6 whatever the mode bits say. Two warnings, two lines, two different mistakes.

main { mmc3.bank_select = $46 mmc3.bank_data = 2 }
warning: this bank select changes the MMC3 mapping mode --> both.raster:2:5 | 2 | mmc3.bank_select = $46 | ^^^^^^^^^^^^^^^^^^^^^^ bit 6 moves the fixed PRG bank from $C000 to $8000 = note: reset chose PRG mode 0, a linear 32 KiB map with this code in the fixed bank at $E000; clearing bit 6 keeps that map = note: bits 6 and 7 take effect from whichever bank select was written last, not from the bank data that follows warning: this write repoints the PRG window at $8000 --> both.raster:3:5 | 3 | mmc3.bank_data = 2 | ^^^^^^^^^^^^^^^^^^ R6 is selected, so this replaces $8000-$9FFF = note: reset chose a linear 32 KiB map with R6 = 0 and R7 = 1; the bytes at $8000 are not the ones it mapped from here on = note: PRG bank switching is not supported yet: banks 0 to 2 hold $FF, and bank 3 is a second view of the fixed bank at $E000
