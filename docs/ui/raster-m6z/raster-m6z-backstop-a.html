Option A — the backstop speaks as a rule the author broke

The analyser refuses any timed region whose instructions contain a branch, a jump, a JSR, an RTS or an RTI. This message only appears when raster-sema has not refused the construct first — that is, for a construct nobody has thought of yet.

The source

Stand-in. After this bead, return is refused by sema with a proper message; only a future construct reaches the backstop.

// demo.raster main { cycles(30) pad { return } }

What ships

error: a timed block cannot contain a branch or a jump --> demo.raster:2:5 | 2 | cycles(30) pad { | ^^^^^^^^^^ instruction 2 of this block is $4C, which moves the program counter = note: a timed block's cost is the sum of its instructions, and that holds only while they run one after another error: could not compile demo.raster (1 error)

What it costs

Terse, and it reads like the rest of the compiler. But it tells the author to fix something they cannot see (an opcode index into generated code) and it does not admit that reaching this message means rasterc failed to refuse the construct earlier with a message that would have named the construct. Nobody reports it, so the gap in sema stays open.
