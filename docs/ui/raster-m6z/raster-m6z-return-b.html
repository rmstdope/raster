Option B — short headline, the explanation in notes

The same refusal, in the shape the timing diagnostics already use. Requires SemanticError to grow a label and notes — which would change how all eleven existing refusals could read, though this bead would convert only the new one.

What it costs

The other ten refusals keep working unchanged, reading as they do now, until somebody converts them. That conversion is a separate bead, not this one.
