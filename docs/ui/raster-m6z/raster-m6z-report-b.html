Q5 Option B — let cycles(?) through, and mark the number as a floor

A cycles(?) block constrains nothing, so a wrong number breaks no ROM — it only misinforms. This option keeps the block compiling and labels what the number actually is.

What Option B ships

$ rasterc r.raster -o r.nes Compiled r.raster -> r.nes mapper MMC3 (4), NTSC prg 32 KiB, 4 banks of 8 KiB chr 8 KiB RAM fixed $E000-$FFFF, 81 of 8186 bytes used entry reset $E000, nmi $E050, irq $E050 cycles hblank: at least 12 cycles (this block branches, so its cost is not a single number)

Keeps a debugging aid working on code that is still being shaped. But it means one kind of timed block is costed by a model that has just declared itself unable to cost it, and the summary grows a second format. The whole point of §6.4 is that "I cannot prove this" is an error and not a shrug.
