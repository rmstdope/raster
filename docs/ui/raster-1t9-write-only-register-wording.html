AGREED · THE WORDING

Every message, label and note as it ships

One message for every read, wherever it is. The register's own name is in the message, the port's address is under the carets, and the notes say where the read came from, what a real read of that address returns, and what to do instead. {name} and {addr} below are the register's source name and its address as four uppercase hex digits.

The message — the same in every position

`{name}` cannot be read

e.g. `mmc3.bank_select` cannot be read, `ppu.mask` cannot be read.

The label — under the carets

${addr} is a write-only port

e.g. $8000 is a write-only port, $2001 is a write-only port.

Note 1 — only on a compound assignment

`{op}` reads its destination before it writes, so this reads ${addr}

{op} is the operator as written: +=, -=, *= or /=. This note is absent on a read the author wrote out, because there the read is on the line in front of them. One rendered line; it does not wrap.

Note 2 — what a read of that address really returns

Two forms. An MMC3 port ($8000 and above):

reading ${addr} returns a byte of your own program from the PRG bank mapped there, not the last value written

A PPU port ($2000-$2007):

reading ${addr} returns whatever was last on the PPU's data bus, not the last value written

Note 3 — what to do instead

keep what you wrote in a variable of your own and write the whole value

One constant string, the same for all thirteen registers. No worked example and no invented variable name: an example would interpolate a name the author may already be using, and the sentence is the whole of the fix.

Assembled — the compound assignment, all three notes

error: `mmc3.bank_select` cannot be read --> demo.raster:2:5 | 2 | mmc3.bank_select += $80 | ^^^^^^^^^^^^^^^^ $8000 is a write-only port = note: `+=` reads its destination before it writes, so this reads $8000 = note: reading $8000 returns a byte of your own program from the PRG bank mapped there, not the last value written = note: keep what you wrote in a variable of your own and write the whole value

Assembled — a read the author wrote, two notes

error: `ppu.scroll` cannot be read --> demo.raster:2:21 | 2 | var saved: u8 = ppu.scroll | ^^^^^^^^^^ $2005 is a write-only port = note: reading $2005 returns whatever was last on the PPU's data bus, not the last value written = note: keep what you wrote in a variable of your own and write the whole value

What the refusal does not carry

No “this release compiles ...” note. That list belongs to a construct the specification defines and this release has not built yet; a read of a write-only port is not coming later, so the refusal carries only its own three notes.
