Wording A — name the bit and the mode it sets

The message says what the register just did; the notes say what reset had chosen and how to keep it. An author who knows the MMC3 recognises it instantly; one who does not is taught the bit.

1 · Bit 7 — CHR A12 inversion

warning: this bank select changes the MMC3 mapping mode --> demo.raster:5:5 | 5 | mmc3.bank_select = $80 | ^^^^^^^^^^^^^^^^^^^^^^ bit 7 swaps the two pattern tables from here on = note: reset chose CHR A12 inversion off, so pattern table 0 is at PPU $0000; clearing bit 7 keeps that map = note: bits 6 and 7 take effect from whichever bank select was written last, not from the bank data that follows

2 · Bit 6 — PRG mode 1

warning: this bank select changes the MMC3 mapping mode --> prg.raster:5:5 | 5 | mmc3.bank_select = $46 | ^^^^^^^^^^^^^^^^^^^^^^ bit 6 moves the fixed PRG bank from $C000 to $8000 = note: reset chose PRG mode 0, a linear 32 KiB map with this code in the fixed bank at $E000; clearing bit 6 keeps that map = note: bits 6 and 7 take effect from whichever bank select was written last, not from the bank data that follows

3 · Both bits set at once — one warning, both labels

warning: this bank select changes the MMC3 mapping mode --> both.raster:5:5 | 5 | mmc3.bank_select = $C0 | ^^^^^^^^^^^^^^^^^^^^^^ bit 6 moves the fixed PRG bank and bit 7 swaps the pattern tables = note: reset chose PRG mode 0 and CHR A12 inversion off: a linear 32 KiB map, and pattern table 0 at PPU $0000 = note: bits 6 and 7 take effect from whichever bank select was written last, not from the bank data that follows

4 · A value rasterc cannot fold

warning: rasterc cannot tell whether this bank select changes the mapping mode --> dynamic.raster:7:5 | 7 | mmc3.bank_select = which | ^^^^^^^^^^^^^^^^^^^^^^^^ this value is not a constant, so bits 6 and 7 are unknown here = note: bit 6 is PRG mode and bit 7 is CHR A12 inversion; keeping both clear keeps the map reset chose
